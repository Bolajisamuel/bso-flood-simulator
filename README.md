# BSO Flood Simulator

### A Web-Based GIS Platform for Flood Simulation and Flood Susceptibility Assessment

**Live Application:** https://bso-flood-simulator.onrender.com

**Developer:** Bolaji Samuel Ogunlana

---

## 1. Project Overview

BSO Flood Simulator is a web-based Geographic Information System (GIS) application developed to support flood simulation, spatial analysis and flood susceptibility assessment.

The platform integrates rainfall, elevation and slope information to support the identification and visualisation of areas that may be more susceptible to flooding.

It provides an interactive mapping environment where users can define a study area, select an analysis method, examine spatial results and generate PDF reports.

The project demonstrates how GIS, web technologies and software development can be combined to create accessible tools for environmental analysis and decision support.

## 2. Key Features

- **Interactive GIS Mapping:** Explore geographical locations and define study areas using an interactive map.
- **Water Level Simulation:** Explore flood scenarios using the application's water-level simulation functionality.
- **Rainfall Analysis:** Retrieve historical rainfall information for spatial analysis.
- **Elevation Analysis:** Examine elevation patterns within a selected study area.
- **Slope Analysis:** Calculate and visualise terrain slope.
- **Flood Susceptibility Index (FSI):** Combine rainfall, elevation and slope using a weighted overlay approach.
- **Customisable Reclassification:** Adjust factor classes, classification ranges, normalised scores and factor weights.
- **OpenStreetMap Integration:** Retrieve and examine mapped features within the study area.
- **Risk Classification:** Visualise susceptibility levels using five categories: Very Low, Low, Moderate, High and Very High.
- **PDF Report Generation:** Generate reports containing maps, statistics, charts, methodology and feature summaries.
- **Web-Based Access:** Access the application through a browser without installing desktop GIS software.
